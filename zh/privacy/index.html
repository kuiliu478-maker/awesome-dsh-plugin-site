隐私政策

最后更新 2026-08-30。本页按代码写，不按意图写——下面每一条都能在构建本站的仓库里核对。如果哪一条和站点实际行为对不上，那是 bug，请告诉我们。

一句话版本

这是一个静态站点，没有账号，我们也不运营任何服务器。它统计页面访问量但无法识别你是谁，自身也不在你的浏览器里存任何东西。页面上有 Google 广告，广告会用到 cookie。

访问统计

我们使用 Cloudflare Web Analytics。它不用 cookie，不做浏览器指纹，也不跨站跟踪你。它记录页面访问量和粗粒度的技术信息——来源页、国家/地区、浏览器与设备类别——由 Cloudflare 聚合。我们看到的是数字，不是个人，也没有任何办法从里面把你单独识别出来。详见 Cloudflare Web Analytics。

Cookie 与浏览器存储

本站自身不设置 cookie；Google 会为广告设置 cookie，见广告一节。本站不写入 localStorage 或 sessionStorage。你的筛选、排序和搜索状态保存在 URL 里，除非你自己复制链接，否则它不会离开你的浏览器。

一个页面会加载什么

字体和样式表都由本域名提供，没有第三方网络字体。没有社交组件，没有代码管理器（tag manager）；除上面提到的统计脚本、下文所述的广告脚本，以及页面内少量筛选逻辑外，没有其他脚本。可选的评论客户端在你把评论面板滚动到视口附近之前不会出现在页面中或发起请求；只要你打开页面后没有向下滚动到评论区，页面就不会为此联系任何第三方。

社区评论

插件详情页可通过 Giscus 提供评论；它是一个由 GitHub Discussions 支撑的开源组件。你选择加载评论后，浏览器会连接 giscus.app 与 GitHub。评论、反应、GitHub 用户名和时间戳会公开保存在本仓库的 GitHub Discussions 中；发表内容需要 GitHub 账号。Giscus 与 GitHub 会依照各自的条款和隐私政策处理这次交互。本站不会保存评论副本，也绝不会为未滚动到评论区的访客请求该组件。

插件页面里的图片

每个插件页面会转载该项目的 README，其中可能包含图片。README 由第三方撰写，因此其中的图片本会让你的浏览器向我们无法控制的主机发起请求——追踪像素正是这样进入页面的。所以我们把这些图片限制在 GitHub 自有托管（raw.githubusercontent.com、user-images.githubusercontent.com、camo.githubusercontent.com、github.com）范围内，其余一律丢弃并保留其替代文字。由于本站本身就由 GitHub Pages 提供服务，GitHub 已经会收到你对页面本身的请求——因此保留下来的图片不会引入任何原本不在链路上的第三方。

托管

本站由 GitHub Pages 提供服务。和任何 Web 服务器一样，GitHub 需要收到你的 IP 地址才能响应请求。详见 GitHub 隐私声明。

你主动点击的链接

列表会链接到 GitHub 仓库、npm 包以及插件作者自己的站点。是否点击由你决定，点击之后你就到了别人的站点上，适用他们的条款。我们不会在这些链接上附加跟踪参数。

目录数据文件

/plugins.json 是公开发布、供任何人读取的，包括 dsh-market 插件和第三方工具。它描述的是插件本身——名称、描述、分类、安装命令——不包含任何关于本站访客的信息。

参与贡献

投稿通过 GitHub 的 pull request 提交，适用 GitHub 的条款，并具有公开仓库应有的可见性。本网站不接收任何投稿；可选的评论界面只会写入 GitHub Discussions，不会写入我们运营的表单或服务器。

广告

本站有 Google AdSense 广告，脚本从 pagead2.googlesyndication.com 加载。Google 会设置 cookie 用于投放和衡量广告，并在每次广告请求中收到你的 IP 地址。你可以在 我的广告中心 更改 Google 对你数据的使用。
